## 2. Soundness

**(a) Engine naturality over `Lvl1Reach m`: plausible for all three rules; no `m`-dependent branching found.**
- `m` enters `LocStep` only through the output lists `lvl1WeightOuts0/EdgeOuts0/GGOuts0 m` (`LWLvl1.lean:3229-3275`); the side conditions `hp hx hv hwf hbad hnb hy hp1 hq1` read `P.g.solid`, `lvl1DegAt`, `lvl1ChargeAt` only.
- Inside the outputs `m` is a coefficient: `owxExt … m`/`m^3` set `coeff := m^k · Γ.coeff` (`LWWeightExp.lean:658-697`, `LWEdgeExp.lean:600-616`); `lwSplitLoops m` multiplies by `m` or `star m` (`LWVocab.lean:1209-1214`); the only branching in the constructors (`oe1xDs`, `LWEdgeExp.lean:1192-1196`) is on edge structure (`σ`, `src`, `dst`). `partition m` filters on `Consistent` only and uses `m` only via `splitWeights` (`LWVocab.lean:1295-1304`): no term is dropped because a coefficient vanishes. `Normal`, `LocStd`, counters, `scalingSize`, `Lvl1Good` do not read `coeff` (`LWVocab.lean:990-993`, `LWLvl1.lean:3204-3206`); only `sizeConst` reads `|coeff|` (`LWSizeClaim.lean:1098`), which is 1 at `|m| = 1`.
- So every output at `m` is `ev m` of an X-output with tags `(j, j')` and a real base coefficient (signs from `withDots`, `LWVocab.lean:1095`); conj twists swap `(j, j')` (`coeff ↦ star coeff`, `LWSymm.lean:104`). The X-carrier cannot be "the `m = 1` instance with tags" (at `m = 1`, `m` and `m̄` coincide): the tags must be tracked per constructor, as `lwSplitLoopsX` does. This is bookkeeping, not mathematics.
- Two design points the pin must get right: (i) the recursion. `lvl1_exists_aux` is WF on `Lvl1Mu K` with the cutoff `K` and `errs` (`LWLvl1.lean:3840-3850`); T2307's `expandG` is fuel-based with `none` = leaf (ticket T2307 target 3). The engine needs the WF/cutoff form (depth is not bounded a priori), so "T2265a states its induction for an abstract step" (1356 O6) buys little; the engine should mirror `lvl1_exists_aux` on the X-carrier and lift the step from `lvl1_exists_step 1` (`:3655`) by cases on the constructor. (ii) the identity hypotheses `∀ a, M a a = m`, `m ≠ 0`, `z + u m = −m⁻¹` (`LocalRegular6d.lean:1118-1125`) are per `m`; the pin is `∃ outsX errsX, ∀ m ≠ 0, …` with `outs := outsX.map (ev m)`. The LocReg1–6 transport is then `lvl1_induction` at each `m` as today (`:1127-1132`).
