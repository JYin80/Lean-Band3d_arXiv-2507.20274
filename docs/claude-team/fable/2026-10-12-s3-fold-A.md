## §2 The pair sum

### §2.1 Why the literal split loses `(L^d/(W^d B_0))^{1/2}` [proved for the upper bound; the loss is a counter-scaling]

Fix `(c₁,c₂)`, `X = Ǧ`, `Y = ǦE_bǦ^*E_aǦ`. Cauchy–Schwarz over `(o,o')` gives `|Tr(PXPY)| ≤ (𝓛̊^{(2)}_{(c₁,c₂)})^{1/2} (𝓛̊^{(6)}_{(c₂,b,a,c₁,a,b)})^{1/2}` ✓. The 2-loop factor does not see `a, b`; all decay in `c₁, c₂` now sits in `𝓛^{(6)}`, under the root. Summing with the weight: by the optimality of Cauchy–Schwarz, any reweighting `|M|² = (|M| w)(|M|/w)` gives at best `Σ_{c₁,c₂}|M|²(𝓛^{(2)}𝓛^{(6)})^{1/2}`. What is provable about it:
- `𝓛̊^{(2)}_{(c₁,c₂)} ≺ W^{-d}B_0` (no information on `c₁`).
- `Σ_{c₁,c₂}|M_{c₁c₂}|² 𝓛̊^{(6)}_{(c₂,b,a,c₁,a,b)} ≤ Σ_{c₁,c₂} 𝓛̊^{(6)} ≺ (W^dη)^{-2}(W^{-d}B_0)^3`: positivity — `Σ_{c₁}|M_{c₁c₂}|² ǦE_{c₁}Ǧ^* = Ǧ D Ǧ^*` with `0 ≤ D = Σ_{c₁}|M_{c₁c₂}|²E_{c₁} ≤ W^{-d}` so `Tr(Z^*ǦDǦ^*Z) ≤ W^{-d}Tr(Z^*ǦǦ^*Z)` — then Ward at `c₁` and at `c₂` (both sit between opposite charges).
- Hence `Σ|M|²(𝓛^{(2)})^{1/2}(𝓛^{(6)})^{1/2} ≤ (Σ|M|²𝓛^{(2)})^{1/2}(Σ|M|²𝓛^{(6)})^{1/2} ≺ (L^d W^{-d}B_0)^{1/2} · (W^dη)^{-1}(W^{-d}B_0)^{3/2} = η^{-1}Ψ^5 · (L^d/(W^dB_0))^{1/2}`.
The only available decay for `n ≥ 3` loops is the `W^{-D}` cutoff beyond `ℓ_t W^{τ'}` (fourth premise of `twSteps`); it replaces `L^d` by `(ℓ_tW^{τ'})^d`, still `≫ W^dB_0` for small `η` (`ℓ_t^d/B_0 ≈ λ^{d+2}η^{-d/2}`). [heuristic] The true size of `Σ(𝓛^{(6)})^{1/2}` is fine (two decays `B_{|c₁−a|}B_{|c₂−b|}` under one root, `Σ_c (B_{|c−a|}B_{|c−b|})^{1/2} ≲ η^{-1}` in `d ≥ 3`), but no pin states a polynomial profile for 6-loops. So the literal (A) is dead with the merged pins.

### §2.2 The corrected fold (A′) [proved]

Write `R := Ǧ E_b Ǧ^*` (so `Σ_{y∈[b]} Ǧ_{(c₂,o'),y} \bar Ǧ_{xy} = W^d R_{(c₂,o'),x}`) and
`Σ := Σ_{c₁,c₂}(M_{c₁c₂})² Tr(E_aǦP_{c₁c₂}ǦP_{c₁c₂}ǦE_bǦ^*) = W^{-3d} Σ_{x∈[a]} Σ_{c₁,c₂,o,o'} (M_{c₁c₂})² Ǧ_{x,(c₁,o)} Ǧ_{(c₂,o),(c₁,o')} R_{(c₂,o'),x}.`

**One Cauchy–Schwarz over the five indices `(x, c₁, c₂, o, o')`**, weight `|M_{c₁c₂}|²`, split `[Ǧ_{x,(c₁,o)} Ǧ_{(c₂,o),(c₁,o')}] · [R_{(c₂,o'),x}]`:

`|Σ| ≤ W^{-3d} F₁^{1/2} F₂^{1/2}`,
`F₁ := Σ_{x,c₁,c₂,o,o'} |M_{c₁c₂}|² |Ǧ_{x,(c₁,o)}|² |Ǧ_{(c₂,o),(c₁,o')}|²`,
`F₂ := Σ_{x,c₁,c₂,o,o'} |M_{c₁c₂}|² |R_{(c₂,o'),x}|²`.

**`F₁`** (which index against what):
1. `o'` against the entrywise law: `Σ_{o'}|Ǧ_{(c₂,o),(c₁,o')}|² = Σ_{v∈[c₁]}|Ǧ_{(c₂,o),v}|² ≺ W^d·W^{-d}B_0 = B_0`, uniformly in `(c₁,c₂,o)` (polynomially many, union bound).
2. `c₂` against the `M`-Ward identity: `Σ_{c₂}|M_{c₁c₂}|² = 1`.
3. `(c₁,o)` against the resolvent Ward identity at `x`: `Σ_{c₁,o}|Ǧ_{x,(c₁,o)}|² = Σ_v|Ǧ_{xv}|² = ‖Ǧ^*e_x‖² ≤ 2‖G^*e_x‖² + 2‖M^*e_x‖² = 2η^{-1}Im G_{xx} + 2Σ_c|M^{(B)}_{[x]c}|² = 2η^{-1}Im G_{xx} + 2 ≺ η^{-1}`.
4. `x ∈ [a]`: `W^d` terms.
So `F₁ ≺ B_0 W^d η^{-1}`.

**`F₂`**:
1. `o` is absent: factor `W^d`. `c₁` against the `M`-Ward identity: `Σ_{c₁}|M_{c₁c₂}|² = 1` (symmetry of `M^{(B)}`).
2. `(c₂,o')` against Ward at `x`: `Σ_{c₂,o'}|R_{(c₂,o'),x}|² = ‖R e_x‖² = ‖Ǧφ_x‖²`, `φ_x := E_bǦ^*e_x` (supported in `[b]`). Positivity: `‖Ǧφ‖² ≤ 2‖Gφ‖² + 2‖Mφ‖² = 2η^{-1}⟨φ,(Im G)φ⟩ + 2‖φ‖²`, using `G^*G = Im G/η` and `Π_bM^*MΠ_b = Π_b` (entries `(M^*M)_{uv} = δ_{o(u)o(v)}Σ_c \bar M^{(B)}_{c[u]}M^{(B)}_{c[v]} = δ_{uv}` for `u,v ∈ [b]`: the `M`-Ward identity again).
3. `x ∈ [a]`: `Σ_x ⟨φ_x,(Im G)φ_x⟩ = W^d Tr(E_aǦE_b(Im G)E_bǦ^*)` and `Σ_x‖φ_x‖² = W^{-2d}Σ_{x∈[a],y∈[b]}|Ǧ_{xy}|² = 𝓛̊^{(2)}_{(a,b)}`.
   `Tr(E_aǦE_b(Im G)E_bǦ^*) = (2i)^{-1}[Tr(E_aǦE_bGE_bǦ^*) − Tr(E_aǦE_bG^*E_bǦ^*)]`: two 3-loops on `(a,b,b)` with legs `(Ǧ, G^{(±)}, Ǧ^*)`. Expanding the circled legs (`E_cME_{c'} = δ_{cc'}W^{-d}mE_c`) they are `𝓛^{(3)} + O(W^{-d}𝓛^{(2)}) + O(W^{-2d})`, so `≺ (W^{-d}B_0)^2`.

**Total:** `|Σ| ≺ W^{-3d}(B_0W^dη^{-1})^{1/2}(η^{-1}B_0^2)^{1/2} = η^{-1} W^{-5d/2} B_0^{3/2} = η^{-1}(W^{-d}B_0)^{5/2} · B_0^{-1}`. Since `B_{t,0} ≥ (λ²+η)^{-1} ≥ (𝔡^{-2}+1)^{-1}`, the target `η^{-1}(W^{-d}B_{t,0})^{5/2}` holds with a constant. ∎

Where the square root sits: on `F₁` and `F₂`, each a *complete* sum (every index is either a Ward sum, an `M`-Ward sum, a block volume, or the entrywise maximum).
