## 二、流本身：可以原样替换

`1_2_Intro_model_result.tex:684–691`，论文自己写着这个 flow
「**与 1D、2D 的完全相同，只差一个与维数有关的标度 `W^{-d}`**」：

```
H_t = ... , (B_t)_{xy} 独立复布朗运动（Hermitian 约束），t^{-1/2} B_t 是 GUE
```

所以一时刻边缘律就是 `√t · X`，`X` 是一个固定的高斯带矩阵——
**正是那份文档提的 `H_u := √u · X` 替换，逐字适用**。这一段不需要为 d ≥ 3 重新论证。

## 三、枢纽：生成元二阶项 ↔ 二次变差（**已找到**）

那份文档说「先去你们的论文里找这个对应。找得到，路就通；找不到，别开工。」

找到了，而且论文把它单独命名了：

* `1_2_Intro_model_result.tex:84,96`：「鞅项 `dE^{M,(n)}` 的**二次变差**依赖 `(2n+2)`-loop」；
* `3_5_Loop_Hierarchy.tex:166–178`，`\begin{definition}[Quadratic variation loop]\label{def:CALE}`：
  「以下记号**对应 `(def_Edif)` 中鞅项的二次变差**」，给出 `(E ⊗ E)^{M,(n)}_{t,σ,a,a'}`。

而 BDG 引理 `lem:DIfREP` 的右端**正是这个张量**。所以生成元恒等式作用在 `|F|^{2p}` 上产生的二阶项，
落点与论文已经算好的 `(E ⊗ E)^{M,(n)}` 一致——**论文那一大段估计原封不动留着，只是改由生成元产出**。

## 四、最要紧的一条：关键引理的陈述**已经是矩不等式**

那份文档 §5 说：「**先看你们那条关键引理的陈述是不是逐路径的**：如果是，改动预算完全不同，要提前跟作者谈。」

`3_5_Loop_Hierarchy.tex:216–240`，`\begin{lemma}[Lemma 5.5 of [YY_25]]\label{lem:DIfREP}`：

```
(aaswtghh)   E[ ∫_s^τ dE^{M,(n)}_{u,σ,a} ]^{2p}  ≤  C_{n,p} · E( ∫_s^τ (E⊗E)^{M,(n)}_{u,σ,a,a} du )^p
(alu9_STime) E[ ∫_s^t (U^{(n)}_{u,t,σ} ∘ dE^{M,(n)}_{u,σ})_a ]^{2p}  ≤  C_{n,p} · E( ∫_s^t ((U⊗U) ∘ (E⊗E))_{a,a} du )^p
```

**两边都是期望，BDG 只出现在证明里**——与 d = 1 的 (5.24) 同一形状。
**⇒ 改动预算是「零处陈述改动、零处重新编号」的那一种。**

还有一个顺带的好消息：**真正和演化核一起用的那条 `(alu9_STime)`，积分区间是确定性的 `[s,t]`，不是 `[s,τ]`**。
带停时的只有第一条。

## 五、三处停时，但是同一个模式

d = 1 只有一处（(5.43)）；这里有三处：

| # | 位置 | 定义 | 怎么用 |
|---|---|---|---|
| 1 | `3_5:532`，`eq:def2_stopping` | `T := inf{u ≥ s : Ĵ^{K_u}_{u,D} ≥ (W^{-d}B_{u,0})^{1/6}}`，`τ := t ∧ T` | `3_5:568` 证 `T ≥ t` whp，**结论是「(eq:Gronwall_dervJuD) 对所有 u ∈ [s,t] 成立」** |
| 2 | `3_5:2369`，`eq:def_TTT` | `T := inf{u ≥ s : max\|(L−K)^{(2)}\|/T_{u,D} ≥ W^ε}` | `lem:pf_step5` 证 `T ≥ t` whp |
| 3 | `7_8:2012`，`eq:def2_stopping_BA` | 与 #1 同形，块 Anderson 那一支 | 与 #1 同一论证 |

**三处都是首次越界时刻，且每一处的收尾都是「`T ≥ t` whp，于是估计在整个确定性区间上成立」**——
这正是连续归纳（bootstrap）给出的结论形状。#1 与 #3 字面上是同一个论证的两个模型版本。

**所以工作量不是 3 倍**：bootstrap 那一层写一次，用三次。

## 六、唯一需要跟作者确认的一处

`3_5:2373` 明确写着：

> 「for every `u ≤ T` … so all the estimates below may be applied to the **stopped process** `u ↦ (L−K)^{(2)}_{u∧T}`
> and to the **stopped hierarchy** `(int_K-L_ST)` in place of `(int_K-LcalE_n=2)`」

也就是说，这一处**真的用了停时版的积分方程**，而不只是用停时表示「第一次越界」。
论文同时给了确定性版的 Duhamel 形式 `(int_K-LcalE)`（`3_5:145` 起），所以问题是：

> **这一处能不能改成「在确定性区间上、在归纳假设之下跑同一估计」？**
> d = 1 那边可以（停时真的消失了）。这里 #2 是唯一看起来需要停止过程本身的地方。

**若可以** ⇒ 整篇不需要「停时」这个概念，也就不需要域流，随机层只剩边缘律 + 生成元。
**若不可以** ⇒ 需要一个最小的可选时间概念，预算要另算。**这一条建议直接问作者。**

## 七、`≺` 的不可数并：同样的问题，同样的解法

`1_2_Intro_model_result.tex:228`，Def 2.1 的 `≺` 是**「uniformly in `u`」**，参数集 `U^{(N)}` 可以依赖 `N`——
与 d = 1 同一形状，同一解法（`N^{-C}` 时间网 + 确定性 Lipschitz）。

论文自己在 `1_2:1228` 已经对谱参数 `z` 用了「standard `N^{-C}`-net and perturbation argument」，
**所以这个手法在本文里本来就在用，不是外来的**。

## 八、与 d = 1 的差异清单（照抄之前先读）

1. **停时 3 处而非 1 处**（§五）——同一模式，写一次用三次。
2. **一处用了停止过程本身**（§六）——唯一的未决问题。
3. **`W^{-d}` 标度贯穿**——流、`M`-loop、`K`-loop 的前因子都带 `W^{-d(n-1)}`。
   与随机层无关，但移植 d = 1 的文件时逐处要改。
4. **那份文档 §8 已经警告过的三条**（闭式传播子是 d = 1 的偶然、组合层几何会变、
   涨落平均要一开始就按 `2p` 阶设计）在这里同样适用，且本项目已经踩到第一条：
   RBM3D 走的是接口假设 `PropTH`，没有闭式。
