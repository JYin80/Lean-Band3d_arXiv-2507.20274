### 1.1 Q1. Is P1 right? Yes. Is the pin possibly false? Not shown, not expected; but not locally derivable.
**Two inputs are missing, as the preflight says.**
- **The lower bound.** At `s = t` (allowed: `s ≤ t`), `g_s = g₀` and the hypothesis is the same carrier at the same time. Conjunct 1 then reads `max|𝓛^{(k)}_t| ≺ Bctl_t^{k-1}·Φ_t`, while the hypothesis gives `≺ Bctl_t^{k-1}`. So conjunct 1 at `s = t` already needs `Φ_t ≳ 1` w.h.p. - **The base.** The copied band recursion (`ConArg.lean:125-375`, final constant linear in `Y_1 ≤ B`, `:305`) gives `Y_n ≺ D(B)a^{n-1}`. Turning this into `≺ a^{n-1}Φ_t` needs `Y_1 = max|tr G_tE_a| ≲ Φ_t`, i.e. `|Re| ≲ Im` blockwise. That fails at small `η_t`: the preflight sample has `Y_1/Φ_t = 347`.

**Why the bound is out of local reach (my calculation, not compiled).**
- Take `n` fixed and `t → 1`, which the pin allows (`t n < 1` only). Then `G_t → R = (H_1 − E)^{-1}`, Hermitian, and `Φ_t ≈ η_t·max_c W^{-d}Σ_{x∈c}(R²)_{xx}`.
- For `k = 2`, `σ = (+,−)`: the left side tends to `W^{-2d}Σ_{x∈a,y∈b}|R_{xy}|²`; the right side tends to `η_sB_{s,0}·W^{-2d}·max_cΣ_{x∈c}(R²)_{xx}`.
- With one dominant eigenvector `u`, of block masses `m_a = Σ_{x∈a}|u_x|²`, the bound reads `max_a m_a ≲ W^τ·η_sB_{s,0}`. Here `η_sB_{s,0} ≈ Im m_s((1−s)/(g²+1−s) + L^{-d}) ≥ κL^{-d}`.
- This is block delocalization at scale `L^{-d}`, the content of the main theorem. So it is plausibly true, but not derivable from the time-`s` loop bound.
- For `k ≥ 3` the right side blows up like `η_t^{2-k}`, so nothing is lost there.
- The Ward bound `𝓛^{(2)} ≤ W^{-d}Φ_t/η_t` suffices only when `η_sB_{s,0} ≳ 1`, i.e. `g² ≲ 1 − s`. This agrees with the preflight.
