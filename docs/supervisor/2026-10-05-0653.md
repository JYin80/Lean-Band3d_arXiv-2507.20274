**The chain reaches the pin: yes.**

**ST2-13b feasibility: feasible, with the following route. The 13b ticket should pin this route.**
- **(a) One martingale, with only a deterministic factor depending on `k`.**
  - By definition `uKer μ u w = (1 − uμS)Θ_{wμ}`, and the two factors commute (both are functions of `S^{(B)}`).
  - Hence `Σ_{j<k} (𝒰^{(m)}_{u_j,u_k} ΔMart_j)_a = (T_{u_k} V_k)_a`, where:
    - `T_w := ⊗_i Θ_{wμ_i}`;
    - `V_k := Σ_{j<k} P_j ΔMart_j`;
    - `P_j := ⊗_i (1 − u_j μ_i S)` is deterministic.
  - So `V` is one vector martingale, and only `T_{u_k}` depends on `k`.
- **(b) Coarse time grid.**
  - Take `v_0 < … < v_P` in `[s_n, t_n]` with `v_P = t_n`, spacing `≤ N^{-C'}`, so `P ≤ N^{C'} + 1`. This does not depend on `K`.
  - For each `k`, pick `p` with `u_k ≤ v_p ≤ u_k + N^{-C'}`.
  - `Y^{(p)}_k := T_{v_p} V_k = Σ_{j<k} 𝒰_{u_j,v_p} ΔMart_j` is a martingale in `k` with deterministic, `j`-dependent weights `κ = 𝒰_{u_j,v_p}(a,·)`. These are exactly the general weights of T2180 target 2.
  - T2180 target 1 is maximal over `k ≤ K` with a bound free of `K`. Together with the peeling of T2180 step 3(c), it gives the self-normalised bound for each `(p, a)`, uniformly in `k ≤ K`.
  - The union over `(p, a)` has `≤ N^{C'+m} · O(log N)` events, each of probability `≤ 4 e^{-N^{2ε'}/(64m)}`.
- **(c) Transfer from `v_p` to `u_k`.**
  - Write `X_k − Y^{(p)}_k = (T_{u_k} − T_{v_p}) T_{v_p}^{-1} Y^{(p)}_k`, where `T_v^{-1} = ⊗(1 − vμS)` has norm `≤ 2^m`.
  - `‖T_{u_k} − T_{v_p}‖ ≤ m |v_p − u_k| poly(N)`: use the resolvent identity (the form of `uKer_eq_one_add`) and `‖Θ_{wμ}‖_{∞→∞} ≤ (1−w)^{-1} ≤ 16N` (`difRep_flow_bounds`).
  - On the proxy side, `|STeeUM(u_j, v_p) − STeeUM(u_j, u_k)| ≤ |v_p − u_k| poly(N)` holds deterministically, using the crude bound `‖STeeM‖ ≤ m N (16N)^{2m+2}` (T2180 3(a)).
  - Choose `C' > (3/2)C_m + D/2 + 1`, where `C_m` is the crude exponent. Then both errors are `≤ ¼ N^{ε'−D/2}` for every `ε' > 0`, because `N^{ε'} ≥ 1`. So `CK = CK(m, D)` stays free of `ε'`, as §29 (7) and the pin require.
- **(d) The second-order part needs no coarse grid.** Its threshold `½ N^{ε'}(N^{-D}/2)^{1/2}` is absolute. Apply Doob `L²` to each coordinate of `Σ P_j Y_j`, times `‖T_{u_k}‖ ≤ poly(N)`, and absorb the result into `CK`, as in T2180 3(d).
- **What not to do.** No union bound over `k ≤ K`, because `K` is unbounded: the coarse grid must be in **time**, with its count independent of `K`. This makes the request's "coarse grid in `k`" precise.
- **What 13b needs.**
  - Merged: `uKer`, `UN`, `uKer_eq_one_add`, `norm_uKer_le`, the inverse identity of `Theta`, `doob_L2_max`.
  - From T2180: targets 1–2.
  - New in 13b: the factorisation (a), the coarse-grid bookkeeping, and the proxy comparison.
  - Estimated size ≈ 1200–1800 lines. A split into two is possible. See O2 for what would make reuse from T2180 cheap.
