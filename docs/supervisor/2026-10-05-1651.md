## Answers to REQ-2026-10-05-1628

### 1. Is the contradiction argument right?
**Yes.** It works for any model, not only the band model.

1.1 **The shift (generic form of target 6).** Take data `(M, m, E, ρ, δ)` that meet the hypotheses of `UNStep1Good`. Put `h_n := N_n^{-2}` and define
- `m^h_n(z) := m_n(z) + (i/2)·1{Im z < h_n}`,
- `ρ^h_n := ρ_n + 1/(2π)`.

Then the shifted data meet the same hypotheses:
- **`UNDens m^h E ρ^h δ`** holds with constants `(c, C + 1/2, Lp)`. The imaginary part only grows, the indicator does not depend on `x`, and the limit `η ↓ 0` moves by `1/(2π)`. Target 6 is this statement at `m = msc`, `E = 0`.
- **`UNTrLocal sz M m^h E δ`** is literally the event of `UNTrLocal sz M m E δ`. Its window is `Im z ≥ N^{-1+ε}`, and `N^{-1+ε} ≥ N^{-2} = h_n` for every `ε > 0`. The same holds for `UNTrLocalInit`.
- **`UNNormBound`, `vOU`, `vOUC`, `UNClaimAll(C)`** depend on the model only.

1.2 **`UNStep1Good` is false.**
- Apply it to `(M, m, ρ)` and to `(M, m^h, ρ^h)` with the same `τs` and `D`. Eventually both good events have probability `≥ 1 − N^{-D}`, so they intersect.
- On a common `ω`, both events use the same `v` and the same `t = 1 − e^{-t*} > 0`. By `isFreeConv32_unique` (`FreeConv.lean:676`) the two `mfc` agree on the upper half plane, and limits in `ℝ` are unique. So `ρ'` is the same in both events, and `1/(2π) = |ρ^h_n − ρ_n| ≤ 2N^{-3τs/8}`. This is false for large `n`.
- Hence `UNStep1Good` holds only if **no** model meets its hypotheses. The band model does: by `UNDensBandRow`, by `UNTrLocalBandRow` applied to `UNLocAvgBand`, and by `UNNormBandRow`. These are true statements, the paper's local law and deterministic facts about `msc`.
- The same argument kills `UNStep1GoodC` for any model that meets `UNTrLocalInit`, which the band and BA models are meant to do.

1.3 **`UNInfty1Row`, `UNCore` and `UNCoreC` are false.** This is the two-dilation argument, made precise. Write `A_n(r, O) := E kPoint 1 (O(r·)) E λ(H_{t*})` and `G_n(O) := E kPoint 1 (O(ρ_sc(E)·)) E λ(GUE)`.
- Take the band model, `E' = E`, `k = 1`, the data `(msc, ρ_sc(E))` and `(m^h, ρ^h)`, and `λ := ρ^h/ρ_sc(E) > 1`.
- `UNInfty1` at both data, with `τU ≤ min τ₁`, gives two limits for every test function `O`:
  - `A_n(ρ_sc, O) − G_n(O) → 0`;
  - `A_n(ρ_sc, O(λ·)) − G_n(O) → 0`.
- Apply the first at `O(λ·)` (`isTestFun_comp_smul`) and subtract: `G_n(O(λ·)) − G_n(O) → 0`.
- For the GUE, the bulk one-point function at the microscopic scale gives `G_n(O) → ∫O` and `G_n(O(λ·)) → λ^{-1}∫O`. With `O ≥ 0` and `∫O > 0` this is a contradiction.
- `UNCore` is the same argument with `UNUnivDilAt` and the band `UNClaimAll` (a true consequence of the band rows); `UNCoreC` is identical.
- The GUE fact is classical but not in Lean, so this part stays **argued**.

1.4 **What is not affected.**
- **`UNUnivMainRow`** (`:745`): both sides are dilated by the same `ρ_n`. Under `UNDens`, `ρ_n ∈ [c/π, C/π]`, so the conclusion is a dilated test function, and `UNGreenCorr` covers dilations in `[a, b]`. It is consistent for any such `ρ`; consume it through the projection `UNDens′ → UNDens`.

- Every merged theorem is still a correct implication, so no merged Lean needs rework.

  - four registered owed pins cannot be proved: `UNStep1Good`, `UNInfty1Row`, `UNStep1GoodC`, `UNCoreC`.

### 2. Is `UNDens′` the right strength?
**Yes, in the following shape.**

2.1 **Shape.**
- **Definition:** `UNDens′ m E ρ δ := UNDens m E ρ δ ∧ ∃ c K Lp > 0, ∀ᶠ n, ∀ z z' ∈ B` with `B = {|Re z − E| ≤ δ, 0 < Im z ≤ 1}`:
  - `c ≤ Im m_n z`;
  - `‖m_n z‖ ≤ K`;
  - `‖m_n z − m_n z'‖ ≤ Lp ‖z − z'‖`.
- These are exactly `hbox`, `hlip` of `freeConv_stable_lip` (`FreeConvRegular.lean:1234`) with `E₀ = E` and `A = |E|`.
- Keep the merged `UNDens` as a conjunct:
  - the projection `UNDens′.toUNDens` is then trivial;
  - `UNUnivMainRow` and `unDens_freeConvST` are reused as they are;
  - the reference keeps its `η ≤ 10` bounds.
- The constants come before `∀ᶠ n`, because target 4 fixes `c₀` before `v`, `t`, `ε`.

2.2 **Enough for Step 1 (UN-12).**
- **Band form.** `mV(vOU)(w) = (√s)⁻¹ m_N((√s)⁻¹(w + E))` exactly, with `√s = e^{-t*/2}` and `t = 1 − e^{-t*}`.
  - The strip `|Re w| ≤ c₁`, `c₀t/4 ≤ Im w ≤ 1/2` lies in the window of `UNTrLocal` once `ε' < τs` (T2190 d.4).
  - On the local-law event, by `un_Bctl_le` (`Pins.lean:961`): `ε ≤ e^{t*/2} W^τ Bctl n (1 − Im) ≤ e^{t*/2} W^τ ((lam²W^d)^{-1} + 8/(c₀ N t))`, with `N t ≈ N^{τs}`.
  - So `ε ≤ c₀` eventually, and `C₀(ε + t) ≲ W^τ W^{-2𝔡} + N^{-τs+τ'} + N^{-1+τs}`, which is `≪ N^{-3τs/8}` because `τs ≤ 𝔠𝔡` and `τs < 1`.
  - Target 4's `ρ₀` is the limit `η ↓ 0` of `Im m_n(E + iη)/π`, which is `ρ_n` by the `UNDens` conjunct.
- **`IsRegular32` part.** Unchanged:
  - for `Im ≤ 1`: the box bounds plus the local law;
  - for `1 ≤ η ≤ 10`: `η Im m_N(x + iη)` is nondecreasing in `η` and `Im m_N ≤ 1/η`, so no reference value is needed.
- **C form (`UNStep1GoodC′`, closeness to the unscaled `m_n` from `UNTrLocalInit`).** Apply target 4 to `m̃(ζ) := √s·m_n(√s ζ)`.
  - The box constants change by factors `≤ 2` for small `t`.
  - `ρ₀` moves by `≤ Lp (1 − √s)|E|/π = O(t)`.
  - This step needs the complex Lipschitz bound of `UNDens′`. The merged `UNDens` does not control the boundary value at the shifted point `√s E` uniformly.

2.3 **Satisfied by the data.**
- **Band (`msc`, bulk `E`).**
  - The lower bound comes from clause 1 of `UNDensBandRow` (the window with `η ≤ 10` contains `B`).
  - `‖msc‖ < 1` (`norm_msc_lt_one`).
  - `Lp = 1/(2c²)` from `freeConvST_sub_le` at `u = u' = 0`, `s = 1`, through `freeConvST_zero_eq_msc` (`:1311`).
  - So `UNDensBandRow → UNDensBandRow′` is a short theorem, **not a new owed pin**.
- **BA (class `m_{u_n ⊞ sc_1}`, T2189 `BAm_eq_freeConvST`).**
  - Given only the box lower bound, which BA-C2 must supply for the merged `UNDens` anyway: `K = 1` (target 2), `Lp = 1/(2c²)` (target 1), `ρ_n` from target 3.
  - BA-C2's burden is unchanged. Put the generic lemma "`c ≤ Im freeConvST (u n) 1` on the window ⇒ `UNDens′`" into UN-01c, so that BA-C1b only cites it.

2.4 **The counterexample family is gone (necessary check).**
- Take two data `(m, ρ)`, `(m̃, ρ̃)` that both meet `UNDens′` and `UNTrLocal` for the same model.
- On the common event, `|m_n − m̃_n| ≤ 2W^τ Bctl(1 − η)` at `η = N^{-1/2}`.
- Hence `|ρ_n − ρ̃_n| ≤ (Lp + L̃p) N^{-1/2} + 2W^τ ((lam²W^d)^{-1} + N^{-1/2})`. This tends to `0` and is `≪ N^{-3τs/8}`.
- So the two conclusions of `UNStep1Good′`, and the two dilations in `UNCore′`/`UNInfty1Row′`, are compatible.
- This is a consistency check, not a proof that the primed pins are provable. UN-12's preflight should tabulate 2.2.

2.5 **Weaker alternatives rejected.**
- A uniform `η`-modulus at `E` only (`|Im m_n(E + iη)/π − ρ_n| ≤ ω(η)`): it repairs 2.4, but not target 4, whose Cauchy-estimate and contraction steps (b)–(c) use the complex Lipschitz bound on the whole strip. It also does not handle the shift in the C form.
- A measure-level statement: there is no merged carrier for it (T2190 ticket).
