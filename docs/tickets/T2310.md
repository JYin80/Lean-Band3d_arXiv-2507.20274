## 1. What this ticket proves

```lean
theorem stOeqQtPT'_holds : ∀ d : ℕ, STOeqQtPT' d
```
where `STOeqQtPT'` is the per-time ingredient shape for `STXiBoot'`:
```lean
/-- Per-time `STXiBoot'`: `STXiBoot'` with `Prec` ↦ `PrecPT` in the conclusion.
    Target of `stOeqQtPT'_holds`; lifted to `STXiBoot'`/`STOeqQt'` by S3-18b2. -/
def STXiBootPT' (E s t : ℕ → ℝ) : Prop :=
  ∀ n_ p : ℕ, 2 ≤ n_ → 1 ≤ p → ∀ XL XLK : ℕ → ℕ → ℝ → ℝ,
    (∀ m n u, 1 ≤ XL m n u) → (∀ m n u, 1 ≤ XLK m n u) →
    (∀ m, 1 ≤ m → STlenL n_ p m →
      Prec sz (U := STPair s t) (fun n q ω => STXiL sz n (E n) q.1.1 m ω)
        (fun n q _ => XL m n q.1.2)) →
    (∀ m, 1 ≤ m → m + 1 ≤ n_ →
      Prec sz (U := STPair s t) (fun n q ω => STXiLK sz n (E n) q.1.1 m ω)
        (fun n q _ => XLK m n q.1.2)) →
    PrecPT sz (U := STPair s t) (fun n q ω => STXiLK sz n (E n) q.1.1 n_ ω)
      (fun n q _ => STbootRHS 1 (fun m => XL m n q.1.2) (fun m => XLK m n q.1.2)
        (sz.Bctl n (s n)) n_ p)

def STOeqQtPT' (d : ℕ) : Prop :=
  STIngR d STCaseI (fun sz E s t => STXiBootPT' sz E s t)
```

### 2a. `altQFlow_initQ` — the new computation (~40 lines)

Discharges the `altGridEndQN` hypothesis:
```
∀ σ, ‖STQop (QopAlgebra_mollifier d (sz.L n) m (sz.lam n)) (s n)
         (fun b => sz.STLKM n (E n) (s n) H σ b) a‖
  ≤ ((sz.size n : ℕ) : ℝ) ^ ε₁ * sz.Bctl n (s n) ^ (m + 1 + 1)
```
Strategy (T2302 G3 table, "projected initial loops" row):
1. `STLK s` at `ε₁/2`: gives `‖sz.STLKM n E (s n) H σ a‖ ≤ N^{ε₁/2} · Bctl(s n)^{m+1}` for the input.
2. `startLevelQN` (QLevelsA.lean:421) at `u = s`, `X ≡ 1`, `τN = ε₁/2`:
   promotes from the LKM norm bound to the QOp norm with an extra `N^{τN}` factor.
3. Combine: `N^{τN} · N^{ε₁/2} · Bctl(s n)^{m+2} · 1 ≤ N^{ε₁} · Bctl(s n)^{m+1+1}` by `ε₁/2 + ε₁/2 = ε₁`.

`startLevelQN` hypothesis checklist:
- `hY`: from `STLK s` at `ε₁/2` (for `hY`, `m+1` → `m+1+1`; `X := 1`)
- `hF`: the falloff bound — follows from `STKbound` (gives `‖STLKM‖ ≤ N^{-D}` for far configurations)
- `hYtop`: top LKM norm → from `STLK s` (worst-case over `σ, a`)
- `hϑ`: the mollifier `QopAlgebra_mollifier` satisfies `STMollifierProps` (used in T2302)
- `hσ`: alternating sign `σ (Fin.last m) = !σ 0` — same as T2302's alternating exit family
