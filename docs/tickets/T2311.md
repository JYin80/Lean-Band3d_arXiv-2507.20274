With `PartitionSim` and `ChildrenSim` proved, ticket 4 (Sound) can transport the certificate's classification flags across `Rel` to conclude `LWG5LeafProps`.

**What this proves.** The certificate checker (T2306) works on a computable model where vertex types are `Fin (a+1)` (external) and `Fin b` (internal). The real expansion (T2307) works on packed graphs `PGraph (Fin 2)` whose external vertex type is an abstract type `P.E'`. The simulation relation
  `Rel (N : MNode) (P : PGraph (Fin 2)) : Prop`
asserts that there exist type equivalences `eE : Fin (N.a+1) ≃ P.E'` and `eI : Fin N.b ≃ P.I'` such that `P` is `N.toP` (the model node packed via `N.ext`) with all vertex labels relabelled by `Sum.map eE eI`.

Bridge 1 (`PartitionSim`): for every model node `N` with surjective `ext : Fin 2 → Fin (N.a+1)` and every `m : ℂ`, the model partition `cPartitionX N.g N.ext` and the real partition `(N.g.partition m).map (pcomp (N.toP h))` are in `List.Forall₂` with the relation `(r, Q) ↦ Rel r.2 Q ∧ Q.g.coeff = m^r.1.1 * star m^r.1.2 * r.2.g.coeff`.

Bridge 2 (`ChildrenSim`): for every model node `N`, candidate `c ∈ cands N.g`, the model children `childrenX N c` and the real children `(Cand.toR N h c hc).kids` are in `List.Forall₂` with `(r, Q) ↦ Rel r.2 Q.2 ∧ r.1 = Q.1`.
