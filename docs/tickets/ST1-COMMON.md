# ST-1 common rules (dispatcher V1, 2026-10-03 05:12 UTC; DECISIONS §12, §16, §17, §19)

Every ST-1 ticket (S1-01 … S1-36 of `docs/reports/T2015-portmap.md` part P.7) includes these rules by reference.

1. **Source**: `../RBM2D` at commit `c9a24cf`, read with `git -C ../RBM2D --no-optional-locks show c9a24cf:RBM2D/<file>`; never write there. Port statements and proofs of the listed files (or the listed line ranges), in the order of P.7.
2. **Renaming** (T2002 report (b.9), DECISIONS §12): R1 `d : Sizes` → `sz : Sizes d`; R2 `Z2 L` → `Zd d L`, `Idx L W` → `Idx d L W`; R3 `W ^ 2` → `W ^ d`, `(W * L) ^ 2` / `size` → `(W * L) ^ d` = `sz.size n`, `W⁻²`-type → `W^{-d}`; R4 `Coord/svar/gvar/P` → `CoordF/svarF/gvarF/PF`. The `d = 2` scales of RBM2D (`scaleM`, `ellT`, `tailT`, `ellStar`, `Meta`, `ellz`) become the merged `ellT`, `Bparam`, `Bctl`, `etaT` as the T2015 probe does (portmap P.8). Every `d = 2` token the T2015 portmap lists for a file (columns `W2`, `L2`, `N2`, `inv2`, `d=2`, `Z2`, `1/5`, `scal`) must be accounted for in the prove report: replaced, or shown dimension-free.
3. **Vocabulary**: the merged MD layer (`RBM3D/Defs/{Sizes,StochDomAt}`, `RBM3D/Gauss/{FineModel,LinearForm,DominationAt,BlockAnderson}`, `RBM3D/Loop/GLoopFlow`, `RBM3D/Path/{Walk,Markov,Stop,Azuma}`) replaces RBM2D's `Gauss/Model`, `Defs/StochDom`, `Hierarchy/Loops`, `Path/*` vocabulary; the ST pins and estimate-level definitions are the T2015 probe's (`RBM3D/Probe/T2015Pins.lean` at `752e027` on `t/T2015`, sections 1, 1b, 2; merged by S1-07). Distances: stochastic and endpoint statements use `zdistInf`, propagator and loop statements `zdistD` (D18), exactly as the probe.
4. **Imports**: never `RBM3D` itself; never an ST-2 … ST-6 file (portmap P.4 lists the 13 import cuts; a helper an ST-1 file took from ST-2 is copied as `private`).
5. **Names**: every public name new to RBM3D is grepped against `main` first (CLAUDE.md §5.2); a clash is renamed with the file stem and listed. Helpers no later ticket needs stay `private`.
6. **Statements**: each ported public statement equals RBM2D's after renaming and exponents (script diff in the report; list every residual difference). If a statement must change beyond that, stop and report.
7. **Instances**: a compiled nonempty instance of every endpoint theorem of the ticket (CLAUDE.md §4 step 2), at the MD-1 instance sequence or the T2015 probe's `sz0`/`sz1`.
8. **Axiom registry** (DECISIONS §16, §19, §20; replaces the 05:12 text): `RBM3D/Test/Axioms.lean` is writable in every ST-1 ticket for **appending registry lines only** (one name per line, one-line comment) in the class of DECISIONS §19 / §20: a `Prop`-valued predicate on the sample, the matrix or the parameters (an event, an LDE event, a stability or data condition) that a deterministic lemma takes as hypothesis is **structural**; a result the paper proves and this ticket assumes is **owed** (stop and report if unsure). Before handing over, run the **registry pre-check**: a scratch file outside the repository with `import RBM3D`, `import` of every new module of the ticket, and `#assert_rbm_axioms`, compiled with `lake env lean` (exit 0; output in the report). The root import is added only at merge, so the full build alone does not see a new module.
9. **Acceptance**: `lake build` of the ticket's modules, then the full `lake build` (root `#assert_rbm_axioms` included) before handing over; `#print axioms`: only the three standard axioms; no `sorry`/`admit`/`axiom`/`native_decide`; `git diff main...t/T####` touches only the sole writable files; prove report ≤ 300 lines, script output first, narrative ≤ 40; RBM2D lines cited (file:line at `c9a24cf`); paper-delta candidates `T####a`, … (signed entries cited, not re-proposed: D17–D25, T2015b–h).
